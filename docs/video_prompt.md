# 科普视频通用 Prompt

本文件约定视频的表达思路和视觉风格。制作步骤、环境和交付规格见 [视频详细流程](video_workflow.md)，任务范围由根目录 `AGENTS.md` 确定。

## 风格

- 3Blue1Brown 风格：深色背景，Manim 配色（蓝、青、绿、黄、金、红），公式逐笔“写”出来，场景之间淡入淡出。
- 把公式、定理和核心概念提炼上屏，用动画帮助理解，不追求复杂效果或严格的证明细节。
- 能用图形讲的就用图形讲，如数轴、面积图、曲线、树图和模拟实验；偏理念的内容用大纲、对比表或卡片。
- 适当使用卡通动画，帮助观众抓住文稿的核心思路，有“啊哈，原来如此”的感觉。
- 同一个量在全片中颜色保持一致。封面简洁，适合科普 vlog。

## 内容表达

- 尊重原稿的思路、讲述逻辑、观点和语气；提炼上屏不等于改写配音正文。
- 讲稿每一节都要覆盖，章节标题与原稿小标题对应。
- 数值、公式和历史事实要准确，有不确定的内容不要编。

## 画面节奏

- 画面跟着讲稿逐句推进，每句话对应一个动画节拍，讲到哪里，画面就出现到哪里。
- 有配音时，动画服从音频节奏；无配音时，给字幕和公式留出阅读时间。
