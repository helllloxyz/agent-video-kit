# 科普视频通用 Prompt

目标：让观众看见一个数学关系或物理机制如何成立。每个镜头围绕一个问题，用对象的变化、比较和对应关系推进理解。

## 风格

- 默认参考 3Blue1Brown 的几何讲解方式：深色底、清晰线条、充分留白，围绕一张主图逐步构建关系；文字用于命名、标注和收束结论。
- 使用仓库 Manim 配色：背景 `#0C0C0E`，正文白色，辅助线灰色；蓝 `#58C4DD`、青 `#5CD0B3` 表示主要对象，黄 `#F7D96F` 提示当前关注点，红 `#FC6255` 表示误差、冲突或警示。具体含义按题材确定，同一个量及其公式符号全片同色；单镜头通常使用 2–3 种语义色，突出一个焦点。
- 构图以主图为中心，也可采用“左图右式”或“上现象下解释”。标题、图形、公式、标签按层级对齐；同类文字固定字号与位置。以 1080p 为参考，标题约 56–72px、核心公式 48–64px、标签与字幕 32–40px，长内容分步展示。四周留出约 5% 安全边距，底部另留字幕区。
- 数学内容优先用数轴、几何变换、面积、曲线和树图；物理内容优先用实验示意、受力图、轨迹、场和剖面。只有层次、遮挡或空间关系确实需要时才用 3D；卡通角色或手绘元素须承担指示、操作或类比的作用，并保持全片风格一致。
- 封面只保留一个视觉主体、一个核心问题和少量关键词，适合科普 vlog。

## 内容表达

- 尊重原稿的思路、讲述逻辑、观点和语气；提炼上屏不等于改写配音正文。
- 讲稿每一节都要覆盖，章节标题与原稿小标题对应。
- 一个镜头只解决一个主要问题。适用时按“看见现象 → 改变条件 → 比较结果 → 提炼关系”组织画面，不强行改变原稿顺序。
- 先让图形中的对象、变量或关系可辨认，再显示相应公式；讲到某一项时，同步突出它对应的线段、面积、箭头或轨迹。推导每次呈现一个有意义的变化，并保留观众需要对照的上一步。
- 能展示机制的内容优先设计连续演示。对比表或卡片用于确有分类、并列关系的段落；屏幕正文提炼关键词和结论，完整讲述由配音及字幕承载。
- 数值、公式和历史事实要准确，有不确定的内容不要编。曲线、箭头方向和对象运动须符合原稿的数学或物理关系；示意图、非等比例图和假设参数须标明，不能冒充实测数据。
- 简化证明时保留成立条件；使用类比时说明其边界。画面表达的因果、精度和确定程度不能强于原稿。

## 画面节奏
- 画面按讲述中的意义变化推进：引入对象、改变条件、展示结果、得出结论分别形成节拍。几句话可以共用一张持续变化的主图，同一句也可有多个必要节拍。
- 有配音时服从已有音频与时间轴，关键动作落在相应词句附近；只有段落时间时如实记录估算，不宣称逐词同步。无配音时按视频流程安排字幕阅读时间，并为复杂公式增加停留。
- 同一概念内优先保留对象，让其移动、变形、分解或重新组合；切换话题时再淡入淡出。公式按项或按推导步骤显现，不要求所有内容逐笔书写。
- 标签出现、强调和镜头移动错开，避免同时争夺注意力。非物理性的界面运动使用平滑缓动，通常约 0.3–0.8 秒；物理运动按模型计算。结论形成后通常停留 1–2 秒供观察，具体服从音轨与阅读需要。

## 分镜与预览

- 编码前保存简短分镜表：时间范围及时间来源｜对应原稿段落｜本镜头要回答的问题｜主要对象及起止状态｜动作与公式对应｜最终保留的结论｜准确性风险。内容须具体到“哪个对象怎样变化”。
- 例如讲导数：保留曲线与两点，让第二点沿曲线靠近第一点，割线随之转动趋近切线；同时对应突出公式中的 `Δx` 与 `Δy`，最后保留切线和极限式。讲抛体运动：在轨迹上保留同一运动点，分解水平与竖直速度，按同一模型更新箭头和坐标。例子仅在原稿涉及该内容时使用。
- 先选一个能代表题材难度的镜头做静帧与短片预览，自查后固定配色、字体、线宽、布局和运动方式，再扩展全片。无需额外等待确认，除非用户要求先审方案。
- 按视频流程检查联系表与成片抽帧：焦点明确、文字可读、公式与图形对应、字幕无遮挡；另看短片确认运动方向、变化过程、转场和停留时间。发现问题先修正再继续。

## 想象力
想象力比知识更重要，最后发挥你自己的想象力，尊重原稿的基础上，在画面上你可以自由发挥。
