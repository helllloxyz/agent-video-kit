# 视频任务详细流程

本文件负责执行步骤、环境和交付规格，表达与风格按 [视频 Prompt](video_prompt.md)。视频任务先读取这两份文件；任务范围按根目录 `AGENTS.md`，所有命令和资源路径相对于仓库根目录。

## 接收音频模型的产物

1. 读取任务目录、`manifest.json` 和交接说明，找到原稿、TTS 稿、各段音频、同次字幕及时间轴。已有音频直接复用；明确要求配音但尚无音频时，按 [音频流程](audio_workflow.md) 准备或接收交接。
2. 画面与公式以原始讲稿为准，即使 TTS 读法有误也不改变原式；配音使用已有音轨。
3. `alignment/` 仅记录原稿与 TTS 文本的对应，不含音频时间。服务字幕有音频时间，段落内部按字符插值的时间属于估算。

## 环境与技术

- 使用 Node.js 20+ 与 npm；共享依赖位于 `.local-deps/video`（`@napi-rs/canvas`、`ffmpeg-static`），首次在仓库根执行 `npm ci --prefix .local-deps/video`，按锁文件安装当前平台依赖及 FFmpeg。仓库渲染脚本直接加载共享依赖，各任务无需复制引擎或软链 `node_modules`，也不需要全局 FFmpeg。
- macOS 支持时优先使用 `h264_videotoolbox`，不可用时检测并使用实际可用的 H.264 编码器，如 `libx264`；不假定一定有硬件编码器。
- 按名称检测已安装字体，中文优先 Hiragino Sans GB / Noto Sans CJK SC，公式优先 STIX；缺失时安装开放字体 Noto Sans CJK 与 DejaVu 或 STIX，或按 [脚本接口](video_engine.md#绘图与字体) 指定字体文件。字体不随仓库分发，不依赖固定系统路径；记录实际选择并检查字符覆盖。
- 使用仓库 [渲染脚本](video_engine.md)，将任务分镜放在本次 `video/src/scenes.mjs`，显式传入分镜路径与输出目录。保存任务代码、素材及运行命令，环境缺项时报告，不改全局配置。

## 视频制作

1. 按视频 Prompt 制作分镜和动画节拍，确定画面、字幕及章节对应关系。
2. 有配音时使用同次 SRT 或时间轴。多段连续使用时，按实际音频时长累加偏移，同步调整字幕、画面和章节，不能直接拼接每段从零开始的时间轴。仅有音频时检查可用的转写/对齐工具；估算时间须注明，不为补时间轴重新合成。
3. 无配音时制作无声视频与烧录字幕，按约 4.6 字/秒安排阅读时间。
4. 先生成静帧联系表，检查文字、公式重叠、出界及字幕遮挡；修正后渲染，再抽帧复查并检查时长、字幕同步和章节覆盖。

## 交付与限制

默认输出到当前任务目录下新的 `video/`，保留已有文本、音频和历史成片：

- 成片 mp4：1920×1080，30fps，内嵌章节。
- 字幕 `.srt`。
- `章节.txt`，可直接用于视频简介。
- 封面两张：16:9 和 4:3。
- 渲染代码、依赖/运行说明、静帧及抽帧检查记录。

如实说明未完成的试听、渲染、同步或检查。长任务保存进度供其他模型接续，不发布或对外发送。
